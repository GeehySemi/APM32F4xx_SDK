&par Example Description

This example describes how to use TMR1 for toggling IO.
The IO of LED2  is configed to toggle constantly every one second.
The phenomenon of LED2  constantly flickered alternately.

&par Directory contents

  - TMR/TMR_TimeBase/Source/apm32f4xx_int.c     Interrupt handlers
  - TMR/TMR_TimeBase/Source/main.c              Main program

&par IDE environment

  - MDK-ARM V5.40
  - EWARM V8.50.5.26295
  - Eclipse V2022-06（4.24.0）

&par Hardware and Software environment

  - This example runs on APM32F411 Tiny Devices.
