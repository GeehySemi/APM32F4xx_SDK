&par Example Description

This example shows how to configure the TMR1 peripheral to generate PWM signals
with different duty cycles.The TMR1 waveform can be displayed using an oscilloscope.

using TMR1 CHANNEL1(PA8 and PA7) to output PWM

&par Directory contents

  - TMR/TMR_PWMOutput/Source/apm32f4xx_int.c        Interrupt handlers
  - TMR/TMR_PWMOutput/Source/main.c                 Main program

&par IDE environment

  - MDK-ARM V5.40
  - EWARM V8.50.5.26295
  - Eclipse V2022-06（4.24.0）

&par Hardware and Software environment

  - This example runs on APM32F411 Tiny Devices.
