# APM32F4xx SDK

Official APM32F4xx software development kit from Geehy Semiconductor.

## Current version

- SDK version: V1.5.3
- Official package date: July 3, 2026
- Release notes date: June 16, 2026
- Package SHA-256: `2d9200402bc1247c55b547aa65ce3917c33c47e111f1d46b1b1c32a33449dd03`
- Official download: [APM32F4xx_SDK_V1.5.3.zip](https://global.geehy.com/uploads/tool/APM32F4xx_SDK_V1.5.3.zip)

## Repository contents

- `Boards`: board support files
- `Documents`: SDK documentation
- `Examples`: peripheral, middleware, and board examples
- `Libraries`: CMSIS, device, and peripheral driver libraries
- `Middlewares`: third-party middleware components
- `Package`: device family pack
- `Utilities`: supporting utilities and device description files
- `Release_Notes.html`: official SDK release notes
